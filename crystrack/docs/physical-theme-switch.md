# Premium rocker & scrollbar

Option A: A premium miniature silver ON/OFF light rocker with a subtle violet-blue metallic edge and recessed 3D shadows replaces the flat three-option top-bar toggle. ON selects Light, OFF selects Dark. Adaptive (CrysTrack's time-of-day system, not operating-system system mode) stays in Settings > Appearance and is never deleted. When Adaptive is active the rocker reflects current phase with a small indicator; pressing it makes a manual selection. Scrollbars are slim, rounded, theme-aware and preserve existing scrollbar-hide rails. This pass is visual-only, on the draft upgrade branch.
