# Issue #74 — bidirectional NGN/USD reference calculator (personal-use UX)

CrysTrack's Wealth already supports a display-currency toggle (`₦ NGN` / `$ USD`), sourced from the normal-mode read-only `GET /api/exchange-rate` endpoint. That existing toggle changes **display values only**; all recorded finance entries stay canonical in NGN.

This change adds a separate, prominent **Naira ↔ dollar calculator** in the Wealth header area. Users may type a naira amount to see approximate dollars, or press the accessible swap button and type a dollar amount to see approximate naira. The same **USD→NGN quote** is used in both directions, with BigInt integer-cent fixed-point rounding (half-up) and explicit rejection of absent, invalid, negative or sub-cent input. The calculator cannot post to any financial route; it does not silently convert a recorded Money entry. The input modal still explicitly says `Amount (NGN)`.

In the isolated synthetic Preview, the UI shows an **explicit fake example rate of ₦1,600 per $1** so a reviewer can interact without contacting an exchange provider; it labels the rate *Synthetic illustration only; not live or tradeable*. In normal mode, the existing rate snapshot uses the exchange-rate API, with a cached-rate indicator and age disclosure. When no valid rate is available, the component does **not** fabricate a conversion.

The rate is indicative, not a bank's trading rate; spreads and fees are excluded. A user wishing to keep **USD-denominated source transactions** rather than a reference display needs a separate multi-currency ledger design with stored original units, timestamped rates, fee/provenance data, reversals and balance authority. This PR deliberately **does not** modify SQL, finance writers, financial objects, bills, CSV, budgets, shard accounting, public API contracts, or an actual foreign-exchange transaction.
